# CQA
Отвечай коротко и без лишней воды.
- Official PDFs in docs/ are authoritative; never modify JSON 1.0.
- Modular FastAPI + SQLAlchemy backend, React/TypeScript/Vite/Tailwind frontend.
- Score with Decimal ROUND_HALF_UP, never ask an LLM to calculate totals.
- Preserve every transcript turn and timestamp; evidence uses one-based indices.
- Immutable checklist/evaluation versions; appeals create revisions.
- No secrets, signed URLs, private datasets, audio or database in Git.
- No paid evaluations without explicit budget authorization. Mock is visibly labeled and never exported as AI.
- Run backend tests and frontend build after relevant changes.
