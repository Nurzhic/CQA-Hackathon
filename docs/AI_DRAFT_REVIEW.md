# AI Draft Review

Отдельный просмотр/редактирование AI-assisted черновика, **не независимая человеческая экспертиза**. Он не пишет в A/B/consensus, не участвует в accuracy, не создаёт EvaluationRow и не меняет официальный JSON 1.0.

## Загрузка и проверка

1. Запустите backend и frontend обычными командами из README; при уже работающем сервере перезапустите backend и обновите браузер после обновления кода.
2. Откройте Benchmark → **AI Draft Review** → **«Загрузить AI-черновик»**.
3. Выберите локальный `CQA_AI_DRAFT_18.json` (не больше 2 МБ). Подготовленный файл проверен: все 18 случаев проходят валидацию.
4. Таблица показывает восемь предварительных значений; `⚑` и жёлтый фон указывают на `review_flags`.
5. Нажмите ID диалога, затем нужный criterion_id. Слева полный оригинальный транскрипт с номерами, ролями и timestamps; выбранные evidence подсвечены. Справа — значение, rationale, N/A reason, флаги. При необходимости прокрутите исходные реплики до указанных номеров.

Проверяются точные 18 ID из multilingual-v1, language/split, восемь уникальных criterion_id, соответствие массивов `criteria_order`, строгие boolean/scale значения Official v1, N/A и причина, непустой rationale, существующие уникальные целые one-based evidence, `review_flags`. Номера не исправляются автоматически. Существование evidence не доказывает правильность его смысла.

## Правки и отдельное сохранение

- Меняйте значение, обоснование, исходные номера, причину N/A и флаги. Во время набора неполные поля допустимы только в форме.
- Нажмите **«Применить правки»**: весь черновик повторно проверяется backend. Невалидные правки не применяются.
- **«Отменить правки»** возвращает последнюю принятую версию выбранного диалога.
- **«Сохранить отдельный JSON»** скачивает `CQA_AI_DRAFT_18.edited.json`. Сначала нужно применить или отменить правки.
- Скачанный JSON можно снова выбрать той же кнопкой загрузки. Исходный файл не перезаписывается. Сервер не хранит AI-черновики в SQLite: постоянная отдельная копия — скачанный файл, рабочая форма находится в памяти вкладки. Закрытие/обновление вкладки без скачивания теряет изменения.

## Подтверждение просмотра

После проверки каждого диалога отметьте **«Этот AI-черновик диалога просмотрен (не независимая разметка)»**. Кнопка **«Подтвердить просмотр»** доступна после всех 18 отметок и отсутствия неприменённых правок.

Она повторно валидирует данные и скачивает `CQA_AI_DRAFT_18.reviewed.json` с временем, списком ID и hash точного содержимого. Это декларация просмотра пользователем, не доказательство качества или личности эксперта. Origin остаётся `AI_ASSISTED_DRAFT_NOT_HUMAN`, `ground_truth=false`; metadata declaration — `AI_ASSISTED_REVIEW_NOT_INDEPENDENT`.

Любая применённая правка сбрасывает предыдущие отметки/подтверждение: содержимое нужно проверить заново. Изменённый вне приложения файл со старым review hash отклоняется; загрузите исходную копию без старой metadata review либо редактируйте через интерфейс. Смена manifest/checklist/transcript context также блокирует импорт.

Не загружайте AI draft в «Импорт ручных разметок». Такой документ не соответствует human Annotation и отклоняется сервером. Не копируйте его в независимые A/B: человек, уже видевший AI-оценки, не может считать этот просмотр слепой независимой разметкой. Существующий человеческий workflow остаётся отдельным; инструкция в STAGE4_HUMAN_ANNOTATION_GUIDE.md.

## Формат

`format=cqa-ai-review-draft-v1`; `criteria_order` задаёт порядок восьми элементов в case.values, case.evidence_turns и case.rationales. Разрешена перестановка порядка, если все массивы переставлены согласованно. `na_reasons` — словарь ровно для null-критериев. `review_flags` — массив строк `criterion_id: пояснение`.

Тексты source/warning/turn_numbering и case_field_guide поддержаны; origin/ground_truth принудительно остаются AI/not-human/false. При сохранении добавляются pinned context и review metadata. Официальный формат JSON 1.0 для результатов не используется и не меняется.

API исключительно локальный/read-only к базе:

- POST `/api/benchmark/ai-drafts/validate` — проверить документ;
- GET `/api/benchmark/ai-drafts/cases/{cid}` — исходный Conversation без человеческих ответов;
- POST `/api/benchmark/ai-drafts/review` — проверить и сформировать metadata просмотра для скачивания.

Вызовов MultiAI/других AI-провайдеров нет. В тестах используются только изолированные синтетические fixtures; подготовленный приватный файл не копируется в tests или frontend bundle и исключён из Git.
